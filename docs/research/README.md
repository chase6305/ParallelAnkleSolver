## 两类原生接口与组合方式

第一类是机构族解析后端。每个后端明确输入、输出、单位、分支和奇异性；例如，旋转脚踝使用 `[pitch, roll]`，一般五杆腿使用 `[x, y]`。解析法在已知机构上保留速度和分支可解释性。

第二类是显式约束接口。对新机构，由模型给出闭环方程和导数：

```text
F(q_active, q_passive, x_task) = 0
F_passive dq_passive + F_active dq_active = 0
dq_passive / dq_active = solve(F_passive, -F_active)
```

当分块不为方阵时，需要检查秩和方程相容性；伪逆最小二乘结果不能自动等同于唯一物理解。已实现带阻尼的局部 SVD 求解、变量/残差尺度、区间边界和收敛状态。初值与分支连续性仍由机构适配层提供，解析与数值后端通过闭环残差交叉验证。

这套接口能为多种拓扑提供统一的接入位置，但不意味着能够在没有机构描述、分支信息和初值的情况下全局求解所有腿部并联构型。URDF 模型、主动/被动关节表和闭环连接信息仍需要逐机型核对。

## 引入顺序与验证要求

1. 已完成旋转脚踝的杆长、分支、解析雅可比、FK 和增益映射的有限样本验证。
2. 已增加一般五杆腿解析后端，覆盖不等杆长、非同轴基座、工作分支和装配分支。
3. 已增加显式约束数值求解与分块微分接口，以已知解析模型验证。
4. 待完成：为 HyRoDyn/Gepetto 等框架建立可选参考适配层，核心 Eigen 库保持独立；当前仅核查论文和源码，没有安装或执行这些框架。
5. 待实际机型数据：引入并联膝、空间脚踝或整腿多闭环配置，逐一核对坐标系、主动/被动关节和分支。

每个适配模型至少验证闭环残差、FK/IK 一致性、分支连续性、差分雅可比、奇异/不可达诊断，以及速度与力矩的虚功一致性。论文宣称的性能和覆盖范围与本仓库的实测结果分开记录。
